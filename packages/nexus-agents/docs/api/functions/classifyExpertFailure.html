      Classifies a single failed execution attempt as transient or permanent.

      See the module header for the ordered decision procedure. signal is checked first (mandatory guard): RETRYABLE_ERROR_PATTERNS matches /aborted/i, so without this a cancelled task would otherwise be retried.

      Fails CLOSED on a throwing classifier (#4303): the body reads error.message and walks .cause (via getErrorMessage/extractErrorMessage/isRetryableErrorChain) and calls detector.detect. An Error-like object with a throwing .message or .cause getter would make any of those throw. execute() runs this INSIDE withRetry's isRetryable predicate and again in annotateExhausted, neither of which is try-guarded by withRetry (adapters/retry.ts:339-363 catches only operation()), so an escaping throw would reject the Promise<Result<…>> and break the never-throws contract execute_expert relies on. This single outer guard covers BOTH call sites: any throw during classification → permanent.

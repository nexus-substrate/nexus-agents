    Interface SecurityAuditQuery

    Query filter for retrieving audit events.

    The post-mortem dimensions (#3197) — actionType, actor, violationRule — NARROW to events that actually carry the field (events lacking it are excluded), unlike trustTier's legacy keep-non-applicable behavior. Only dimensions backed by a real event field are offered: resource and policyName from the original ask were dropped because no AuditEvent records them (a filter with no backing field would be dead config); the policy-rule intent is served by violationRule (PolicyGateEvent's violationRules).

    Optional Readonlytracker

    tracker?: ICorrelationTracker

    Correlation tracker this instance uses when OWVoting.aggregate is called WITHOUT a per-call tracker (#3173). Injecting here lets higher-order voting be reused as a building block (autonomous agents, test harnesses, custom pipelines) without coupling to the MCP tool's process-wide singleton or threading the tracker through every call. Omit it to keep the singleton model — the MCP consensus path injects/passes its persistent tracker.

    Optional ReadonlyruleOfTwoViolation

    ruleOfTwoViolation?: {
        rule: string;
        message: string;
        severity: "warn" | "block";
    }

    Rule-of-Two assessment surfaced by the policyEnforcement stage (#3198): present (with severity: 'block') when the effective tier is untrusted AND the configured context has both write and secret access. The firewall is a signal provider — it SURFACES this for the consumer to enforce; it does not hard-block. undefined when the stage is disabled or the rule holds.

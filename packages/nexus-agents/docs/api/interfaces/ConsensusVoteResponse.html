    policyReason?: string

    OptionalpanelWarning

    panelWarning?: string

    Set when the panel was DEGRADED (#3587): some voters errored, so the decision rests on fewer than the requested number of voters. Surfaces a silently-shrunk panel so the result isn't read as a full-strength consensus. Absent when every requested voter returned a real vote.

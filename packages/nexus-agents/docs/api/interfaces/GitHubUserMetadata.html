    Optional ReadonlyaccountAgeDays

    accountAgeDays?: number

    Account/activity fields are OPTIONAL (#3106). When a field is absent (the caller couldn't fetch it — e.g. the firewall before Phase 3 wiring), its signal is SKIPPED rather than fabricated: an unknown value must never be treated as benign (the old hardcoded 365/0) nor as hostile. Only the authorAssociation + injectionFlags signals fire on absent activity data.

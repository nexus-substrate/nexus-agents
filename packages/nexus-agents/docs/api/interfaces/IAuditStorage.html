          Hash-projection version (#3921). ABSENT/1 = the legacy projection ({id,timestamp,category,action,outcome,actor,previousHash}); 2 = the legacy projection PLUS the canonicalized metadata.tierTransition payload, so a tier-transition's integrity-critical payload is hash-covered. Versioned so pre-existing v1 chains keep verifying under their own projection (see AUDIT_HASH_VERSION_TIER_TRANSITION).

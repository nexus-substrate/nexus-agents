# Changelog

This project ships from the npm package [`nexus-agents`](https://www.npmjs.com/package/nexus-agents). Release notes are maintained in [`packages/nexus-agents/CHANGELOG.md`](packages/nexus-agents/CHANGELOG.md), which is auto-generated by [Changesets](https://github.com/changesets/changesets) on every release.

For each release's GitHub page (release notes, SBOM attachments, attestations), see <https://github.com/nexus-substrate/nexus-agents/releases>.

For pre-2.28.0 history that pre-dates the migration to changesets, see the git log: `git log --oneline -- CHANGELOG.md`.

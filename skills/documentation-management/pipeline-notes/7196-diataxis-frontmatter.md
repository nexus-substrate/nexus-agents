PIPELINE NOTE: #7196 (epic #7203) adds a blocking `Diátaxis Frontmatter` job (`diataxis-frontmatter`) to `docs-check.yml` and to the `docs-success` needs list. It runs `scripts/check-diataxis-frontmatter.ts`, which scans `docs/**/*.md` except the generated `docs/api/` and checks the `diataxis: tutorial | how-to | reference | explanation | none` and `audience: user | project` frontmatter defined in `skills/diataxis/SKILL.md`. An invalid value, a list value, an empty key, malformed frontmatter, or `diataxis: none` on a page outside the kinds in `docs/ops/diataxis-none-kinds.json` fails. Missing declarations are a ratchet: the counts of pages missing each key may not grow past `docs/ops/diataxis-frontmatter-baseline.json` (seeded at 220 of 220 pages for both keys). `--update-baseline` rewrites it when the count falls. Zero pages scanned fails as `unmeasured`, and an unreadable baseline or kinds file fails too. The script is also added to the workflow's push `paths`.

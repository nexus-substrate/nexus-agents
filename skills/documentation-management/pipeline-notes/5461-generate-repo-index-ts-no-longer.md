PIPELINE NOTE: generate-repo-index.ts no longer writes a wall-clock stamp (#5461, 2026-09-06) — SEMANTIC for the artifact's diff behaviour. `generated: new Date().toISOString()` left artifacts/repo-index.json and the `**Generated:**` line in docs/reference/capabilities.md, and the generator stripped it before comparing, so it changed exactly when the content changed and never otherwise. It still put every regeneration on the same single line, so two PRs regenerating for unrelated reasons conflicted on it alone, and every `chore(release): version packages` regenerates the artifact — so open PRs went CONFLICTING at each release, and a CONFLICTING PR gets zero pull_request runs, which reads as "no checks". The strip-before-compare logic in hasJsonChanged/hasMdChanged is gone with it; `packageVersion` and `generator` stay because they are content. A "when" is recoverable from the commit that last touched the file. New scripts/generate-repo-index.test.ts asserts both stamps stay absent.

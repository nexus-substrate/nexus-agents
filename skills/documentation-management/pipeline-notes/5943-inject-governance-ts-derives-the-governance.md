PIPELINE NOTE: inject-governance.ts derives the "Governance Version" stamp from the CONTENT of GOVERNANCE_STAMP_SOURCES, not from a commit date (#5943, 2026-09-08) — SEMANTIC for the stamp's format and for what can move it. It was `git log -1 --format=%cs` over the four sources; `%cs` is the committer date and GitHub's squash button rewrites it to the merge moment, so a PR stamped on day 1 and merged on day 2 left main with a stamp the injector would no longer compute, and the NEXT unrelated PR to touch a stamp source failed docs-check's idempotency step (`inject` then `git diff --exit-code CLAUDE.md`, a WHOLE-LINE comparison). The PR that failed was never the one that caused it. Author date (%as) is not a fix — measured, GitHub rewrites that too. The stamp is now a 12-hex sha256 prefix over the four sources' normalised content (CRLF and trailing whitespace stripped) and reads NO git history, so no rewrite can move it; docs-check.yml's fetch-depth: 0 requirement for this script is obsolete. An absent source hashes as a `<absent>` sentinel rather than being skipped, so removing a source MUST change the digest. FIVE coupled sites moved together, and the format regex is now ONE exported constant (GOVERNANCE_STAMP_PATTERN in scripts/governance-stamp-exemption.ts) shared by the renderer, the tests and #5983's ratification exemption, because "every site moved" is only checkable if there is one site to move. The AGENTS.md sync replacer deliberately matches ANY stamp body (`/_Governance Version: [^_\n]+_/`) rather than the current shape: pinned to the new shape it could not convert a line written in the old one, and the first inject left AGENTS.md holding a stale date while CLAUDE.md moved to a digest. The release-validate staleness warning was REMOVED, not re-based: it parsed the date, so under a digest `match?.[1]` is always undefined and the check silently never fires — a check that cannot fail by construction, worse than no check. What it measured is not a defect anyway (governance sources unchanged for 30 days is fine). TWO defects were shipped and caught by the tests written for this change, both worth recording: the first version hashed `join(ROOT, path)` when GOVERNANCE_STAMP_SOURCES entries are ALREADY absolute, so every read fell to the sentinel and the digest was the same whatever any source contained; and the second hashed the absolute path, making the digest `/home/william/...` locally and `/home/runner/...` in CI, which failed the drift check on this change's own first run — the identical failure extract-api-surface.ts documents in its own comments. Paths are hashed relative to ROOT. Ratified 6-1 at supermajority with absolute_quorum; the FIRST vote was rejected on a 3-3 option split after two voters showed one option kept a %cs date on the line and so could not fix a whole-line diff.

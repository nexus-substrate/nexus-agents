PIPELINE NOTE: inject-governance.ts `check` now compares the WHOLE formatted CLAUDE.md regeneration against the on-disk file, not only the GENERATED:FROM_AGENTS block, and a prettier failure inside the check is an actionable message rather than an unhandled rejection (#6087, 2026-09-10) — SEMANTIC for what a green local `governance:check` promises about CI. #6062/#6084 made the block comparison formatter-normalised and deliberately compared ONLY the marker-bounded block, on the reasoning that prettier's view of the rest of the file is not agnostic-body drift. True, but CI's docs-check idempotency step runs `inject` and then `git diff --exit-code CLAUDE.md`, a whole-file diff, so a stripped end-of-file newline or `*emphasis*` prose outside the markers (prettier rewrites it to `_emphasis_`) passed locally and failed in CI — the local pre-check did not mirror what CI enforces, raised by the contrarian seat on the #6084 panel. The check now splices the ON-DISK block into the formatted regeneration and compares that whole text to the file, so the second measurement covers exactly what lies outside the markers; it reports `CLAUDE.md differs outside the generated block — first difference at CLAUDE.md:N` with expected/on-disk lines and the inject remedy. The two causes are measured and rendered INDEPENDENTLY, never if/else-if: a stale block plus a missing EOF newline prints both messages, and the test for that both-non-zero row is the one an else-if mutation fails. The splice is index-based, not `String.replace`, because the replacement-pattern syntax (`$&`) would corrupt a block containing a dollar sign, and CLAUDE.md contains several. The regeneration compared is still the agnostic-block injection alone (plus prettier), not the full `inject` of every section — the count-drift probes cover those sections, and CI's step remains the authority for the full render. Separately, `process.exit((await checkGovernance()) ? 0 : 1)` had no catch, so a malformed `.prettierrc` (which makes `prettier.resolveConfig` reject) printed a stack trace as the only output; the check path now goes through `formatForCheck`, which prints `governance:check: could not format <path>: <prettier message>` and fails the check, exit 1. The #6062 test that stripped the EOF newline and expected a PASS was rewritten — under this change that IS drift, because CI says so; its padded-slice half stays.

`consensus_vote` now discloses where each seat actually answered. Every seat carries `assignedCli` (the CLI the round-robin or `NEXUS_VOTER_MODEL_<ROLE>` pin chose), and a seat that answered on a different CLI or model carries `fallback: { fromCli, fromModel?, reason }`, where `reason` is the adapter error class that moved it — `rate-limit`, `capacity`, `auth`, `timeout`, `sandbox` or `unknown`. The claude adapter's in-family model substitution (an out-of-credits alias retried on the next one) is reported the same way as `reason: 'capacity'`. The response gains `panelDiversity: { distinctModels, fallbacks }`, always present with explicit zeros, and a `panelWarning` is appended when every answering seat of a 3+ panel ran on one model. `costSummary.perVoter[]` rows carry `assignedCli` beside `model`. The CLI summary and the GitHub comment print one line: `Models: 3 distinct, 2 fallbacks (devex: codex→gemini, capacity)`. Before this, a 7-seat panel that fell over onto a single model during a capacity window read identically to a three-model panel. `CompletionResponse.fallbackFrom` is new (additive) for CLI bridges that substitute a model; `isTimeoutText` is exported from `cli-error-helpers`.

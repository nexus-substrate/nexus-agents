## Fast Path: Common Tasks

### Update Documentation Content

```bash
# 1. Edit canonical source
edit docs/architecture/MEMORY_SYSTEM.md  # or relevant file

# 2. Sync to website
npx tsx scripts/sync-docs.ts

# 3. If INDEX.yaml changed, regenerate LLM context
npx tsx scripts/generate-docs.ts

# 4. Verify
npx tsx scripts/sync-docs.ts --check
```

### Add New Document

1. Create file in appropriate `docs/` directory
2. **REQUIRED:** Add entry to `docs/README.md`
3. If public-facing, add mapping to `scripts/sync-docs.ts`
4. Run: `npx tsx scripts/sync-docs.ts`
5. Commit and push

### Change Doc Pipeline

1. Edit pipeline script/config
2. **REQUIRED:** Update `docs/ops/docops-spec.md`
3. **REQUIRED:** Update this skill (`.claude/skills/documentation-management.md`)
4. Run all checks (see Verification below)
5. Commit and push

### Verify Pipeline Health

```bash
npx tsx scripts/sync-docs.ts --check
npx tsx scripts/generate-docs.ts --check
npx tsx scripts/generate-repo-index.ts --check
npx tsx scripts/inject-governance.ts check
cd website && npm run build && cd ..
```

## Enforcement Rules

### Rule 1: Canonical Index Required

All documentation MUST be indexed in `docs/README.md`.

### Rule 2: No Parallel Indexes

`docs/README.md` is the ONLY permitted documentation index.

### Rule 3: Generated Files Must Match Source

CI fails if generated files drift from canonical sources.

### Rule 4: DocOps Changes Require Skill Update

Changes to pipeline files require updating this skill and `docs/ops/docops-spec.md`.

**Pipeline files:**

- `scripts/sync-docs.ts`
- `scripts/generate-docs.ts`
- `scripts/generate-repo-index.ts`
- `scripts/inject-governance.ts`
- `.github/workflows/docs-check.yml`
- `.github/workflows/deploy-docs.yml`
- `website/astro.config.mjs`

## Troubleshooting

### "Website content is out of sync"

```bash
npx tsx scripts/sync-docs.ts
git add website/src/content/docs/
git commit -m "docs: sync website content"
```

### "llms.txt check failed"

```bash
npx tsx scripts/generate-docs.ts
git add docs/llms.txt docs/llms-full.txt
git commit -m "docs: regenerate LLM context"
```

### "Link check failed"

1. Run `npx lychee . --config lychee.toml` to identify broken links
2. Fix links in canonical source
3. Run `npx tsx scripts/sync-docs.ts` if website doc affected

### "New doc not appearing on website"

1. Verify entry exists in `docs/README.md`
2. Add mapping to `scripts/sync-docs.ts` (DOC_MAPPINGS array)
3. Add sidebar entry to `website/astro.config.mjs` if needed
4. Run `npx tsx scripts/sync-docs.ts`

### "CI keeps failing on docs"

```bash
# Run full validation suite locally
pnpm lint
pnpm typecheck
npx tsx scripts/sync-docs.ts --check
npx tsx scripts/generate-docs.ts --check
npx tsx scripts/generate-repo-index.ts --check
npx tsx scripts/inject-governance.ts check
```

## Website Configuration

### Adding Sidebar Items

Edit `website/astro.config.mjs`:

```javascript
sidebar: [
  {
    label: 'Section Name',
    items: [{ label: 'Item Label', slug: 'section/item-slug' }],
  },
];
```

### Adding New Section

1. Create directory in `website/src/content/docs/`
2. Add sidebar group in `website/astro.config.mjs`
3. Add mappings in `scripts/sync-docs.ts`
